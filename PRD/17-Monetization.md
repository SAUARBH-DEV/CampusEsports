# Purpose

This document defines how Kurukshetra will generate sustainable revenue while maintaining a great experience for students, organizers, colleges, and partners.

The initial MVP focuses on growth and adoption. Revenue generation will be introduced gradually without negatively affecting the user experience.

---

# Revenue Philosophy

Our priorities are:

1. Build trust.
2. Build community.
3. Build engagement.
4. Build sustainable revenue.

Growth comes before monetization.
